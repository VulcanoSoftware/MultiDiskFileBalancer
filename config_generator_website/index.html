 Next Steps — How to Run Your Setup

        
Follow these quick steps to launch MultiDisk FileBalancer with your newly generated config.

      


      

        

          
1

          
Save Configuration

          
Place your downloaded config.yml file into the root folder of MultiDisk FileBalancer.

        


        

          
2

          
Install Dependencies

          
Run the installation command in your Linux terminal:

          

            pip install -r requirements.txt
          

        


        

          
3

          
Launch Application

          
Start MultiDisk FileBalancer with sudo privileges for FUSE/NFS support:

          

            sudo python multidisk_filebalancer.py
          

        


        

          
4

          
Access Web Panel

          
Open your browser and navigate to your web panel:

          

            http://<your-server-ip>:5000
          

          
Sign in with the username & password configured in Step 4 above.
